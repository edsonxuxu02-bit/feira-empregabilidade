Instruções para ativar a Sincronização no Firebase:

O projeto está configurado, mas o seu banco de dados precisa ser criado no painel do Firebase.

  1. No painel do Firebase (onde você estava), clique no menu Firestore à esquerda.
  2. Clique no botão azul "Criar banco de dados".
  3. Selecione a opção "Iniciar no modo de teste" e conclua.
  4. Na aba Regras do Firestore, garanta que esteja: allow read, write: if true; e clique em Publicar.
